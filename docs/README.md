# Indice de Documentacion

Documentacion modular del proyecto LiteratureRetrieval:

- [AGENT_NOTES.md](AGENT_NOTES.md): Guia de contexto rapido para agentes de IA y desarrolladores. Resume el estado actual, decisiones tecnicas y requisitos de las fases posteriores.
- [ARCHITECTURE.md](ARCHITECTURE.md): Diagrama de flujo de datos y arquitectura modular del sistema (`src/corpus.py`, `src/nlp.py`, `main.py`).
- [CORPUS_SPEC.md](CORPUS_SPEC.md): Especificacion de las obras literarias, discrepancias resueltas y esquema oficial de columnas del corpus.
- [NLP_PIPELINE.md](NLP_PIPELINE.md): Reglas de limpieza de texto, filtrado sintactico por POS tags y lematizacion con spaCy.
- [SPACY_CONSIDERATIONS.md](SPACY_CONSIDERATIONS.md): Limitaciones, sesgos del modelo en espanol (ej. `olía` -> `oliar`) y casos para el analisis de errores.
- [04_Literature_Retrieval_EN.pdf](04_Literature_Retrieval_EN.pdf): Especificacion oficial completa de la practica de Procesamiento de Lenguaje Natural.
